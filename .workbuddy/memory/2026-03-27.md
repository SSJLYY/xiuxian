- **修复**：将 `application.properties` 中 `spring.security.user.password` 改为 `admin123` 的 BCrypt 哈希 `$2b$10$dd5hCl9Jc05iS4T05pNDPe4Dx3l8Vhnz4l3u/bJ1I0G9nFZs//F7C`
- **管理员登录密码**：`admin` / `admin123`

### 修复2：双重 CORS 配置冲突（P1 Bug）
- **问题**：`CorsConfig.java` 中的 `CorsFilter` Bean 使用 `setAllowedOrigins("*") + setAllowCredentials(true)` 违反 CORS 规范，且与 `SecurityConfig.corsConfigurationSource()` 冲突。
- **修复**：清空 `CorsConfig.java` 中的 `@Bean`，统一使用 `SecurityConfig` 的正确 CORS 配置（`setAllowedOriginPatterns("*")`）

## OfflineNarrativeService.java unchecked 警告修复

### 问题
第 126-127 行 Jackson 反序列化使用 `HashMap.getClass()` 导致 unchecked 警告：
```java
Map<String, Integer> changes = om.readValue(json, new HashMap<String,Integer>().getClass());
// → Class<? extends AbstractMap> 运行时擦除，编译警告
```

### 修复
改用 `TypeReference` 显式声明泛型类型，消除 unchecked 警告：
```java
Map<String, Integer> changes = om.readValue(json,
    new TypeReference<Map<String, Integer>>() {});
```
同时补充了 `Map`、`HashMap` 的 import。

## Java8Compatibility.java unchecked 警告修复

### 问题
`mapOf()` 方法中 `Object...` varargs 转型为泛型 `(K)`、`(V)`，编译器无法在运行时保留类型信息：
```java
map.put((K) keyValues[i], (V) keyValues[i + 1]);  // unchecked cast
```

### 修复
在 `mapOf()` 方法上加 `@SuppressWarnings("unchecked")`。这是该类方法的固有特性（模拟 Java 9 `Map.of()`），调用方保证类型安全，压制警告是正确的。
