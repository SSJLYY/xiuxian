## 项目全量二次检查（注册/登录链路保障，2026-03-25）

**背景**：用户再次更新了代码，要求全面检查确保注册、登录不会出问题。

### 发现并修复的 4 处 P0 问题

1. **`DataInitializer.java` 启动失败 - 致命**
   - 问题：第 24 行 `com.xiuxian.game.mapper.UserMapper`（旧包路径，不存在）
   - 影响：Spring 启动时 Bean 注入失败，应用无法启动
   - 修复：改为 `com.xiuxian.game.modules.player.mapper.UserMapper`

2. **`application.properties` 全局逻辑删除配置 - 致命**
   - 问题：`mybatis-plus.global-config.db-config.logic-delete-field=deleted`，但 `users`、`player_profiles` 表无此字段
   - 影响：MyBatis-Plus 自动拼接 `WHERE deleted=0`，注册后立即查不到用户，登录永远返回"用户不存在"
   - 修复：删除这三行全局 logic-delete 配置

3. **`MybatisPlusConfig.java` 分页插件被条件化 + 危险 return null**
   - 问题：`@ConditionalOnProperty(readwrite=true)` 导致 `readwrite=false`（默认）时分页插件不加载；`sqlSessionFactory()` 返回 null 可能覆盖 Spring Boot 的自动配置
   - 影响：所有分页查询失效（admin后台、排行榜等）
   - 修复：完全重写该类，移除 `@ConditionalOnProperty`，移除危险的 return null 方法

4. **`pom.xml` Redisson 依赖冲突风险**
   - 问题：引入了 `redisson-spring-boot-starter` 但项目中完全未使用
   - 影响：Redisson 自动装配可能与 Spring Data Redis 的 `RedisConnectionFactory` 产生 Bean 冲突，导致 Redis 操作报错
   - 修复：注释掉该依赖

### 验证结果
- 全量 Lint 错误：**0** ✅
- 注册/登录核心链路（AuthController→AuthService→UserMapper/PlayerProfileMapper→JwtTokenProvider）：**完整无断点** ✅
- SecurityConfig 白名单（`/api/auth/login`、`/api/auth/register`）：**正确放行** ✅
- SecurityFilter 跳过 `/api/auth/` 路径：**已确认** ✅
