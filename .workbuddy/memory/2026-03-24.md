## 代码质量审查与修复（本会话）

### 发现并修复的问题

#### 1. PetService.java 和 QuestService.java 随机数使用问题
- **问题**：import 了 `java.util.Random`，但实际代码中 `random.nextDouble()` 未定义
- **原因**：之前会话已添加 `rng()` 静态方法使用 `ThreadLocalRandom`，但忘记移除旧的 import
- **修复**：
  - 移除 `import java.util.Random`
  - 添加 `import java.util.concurrent.ThreadLocalRandom`
  - 替换 PetService 第233行：`random.nextDouble()` → `rng().nextDouble()`
  - 替换 PetService 第143行：`Math.random()` → `rng().nextDouble()`

#### 2. RechargeService.java 订单号生成
- **问题**：使用 `Math.random()` 生成随机数
- **修复**：改为 `ThreadLocalRandom.current().nextInt(10000)`

#### 3. AdminAuthService.java printStackTrace
- **问题**：4处 `e.printStackTrace()`，不符合 Slf4j 日志规范
- **修复**：
  - 添加 `@Slf4j` 注解
  - 全部替换为 `log.error("xxx失败", e)`
  - 位置：登录失败、Token验证失败、登出失败、获取管理员信息失败

### 最终验证结果
- `new Random()` → 0处 ✅
- `Math.random()` → 0处 ✅
- `import java.util.Random` → 0处 ✅
- `printStackTrace()` → 0处 ✅
- `throw new RuntimeException` → 1处（DataInitializer启动失败，合理保留）✅
