## 1. 叙事愿景与主题

### 1.1 核心主题问题

> **「在长生路上，你愿意付出什么代价？」**

这不是一个关于"变强"的故事——每个修仙者都在变强。这是一个关于"你变成了什么"的故事。当修为增长时，人性是否在消退？当永生近在咫尺时，凡尘的一切是否还有意义？

### 1.2 与GDD设计支柱的叙事对齐

| GDD支柱 | 叙事支撑方式 |
|---------|------------|
| 每一分钟挂机都有意义 | 离线事件生成微型故事片段（"你离线时，一只受伤的灵狐出现在你洞府前……"） |
| 每次上线有新鲜感 | NPC对话随时间/境界变化；世界事件影响环境叙事 |
| 选择有重量 | 主线分支影响NPC关系、宗门声望、后续可用剧情 |
| 成长有节奏感 | 境界突破伴随仪式性叙事时刻（心魔对话、师尊寄语） |
| 社交有杠杆，单人也完整 | 宗门有专属剧情线；单人玩家有完整师徒叙事弧线 |

### 1.3 情感弧线

```
玩家情感旅程：

好奇 → 归属 → 挑战 → 迷惘 → 顿悟 → 责任 → 超越

练气期          筑基期          金丹期          元婴期
(好奇/归属)    (挑战/成长)     (迷惘/顿悟)    (责任/超越)
```

### 1.4 叙事原则

1. **不说教**：主题通过玩家体验传递，而非NPC长篇大论
2. **可选深度**：核心路径无任何阅读障碍，深层传说奖励好奇心
3. **世界先于角色**：玩家感受到世界在运转，而非世界围着玩家转
4. **留白有力量**：不是所有问题都有答案，不是所有伏笔都需要回收

## 2. 世界观与传说架构

### 2.1 世界概述

**苍玄界** — 一个灵气充盈的修仙世界。

苍玄界由五大灵脉支撑，灵脉交汇处形成修仙者聚居的"仙城"。世界被分为凡人居住的"下界"和修仙者争夺的"上界"，以一道名为"天堑"的天然屏障分隔。

修仙者通过吸收灵气提升修为，从练气期开始，历经筑基、金丹、元婴……最终目标是渡过天劫，飞升仙界。

但这只是"官方说法"。每一个老修士都知道——飞升之路，万中无一。

### 2.2 传说层级结构

#### 第一层：表面（所有玩家）— 练气期即知

每个玩家在关键路径上会遇到的内容，不需要任何额外探索。

- **苍玄界基本构成**：五脉、仙城、天堑、下界
- **修仙基本常识**：灵气、境界、心魔、天劫
- **当前势力格局**：四大宗门（天剑宗、万法阁、幽冥殿、灵兽山）、散修联盟、凡人王朝
- **新手村"青云镇"**：玩家出生地，一个灵气稀薄但安宁的小镇
- **师尊"苏玄清"**：玩家的引路人，天剑宗外门长老，一位看似普通的老者

#### 第二层：参与（探索者发现）— 筑基期逐渐揭示

通过与NPC深入交谈、阅读散落的笔记和卷轴、探索隐藏区域发现的内容。

- **五灵脉的秘密**：五条灵脉并非自然形成，而是上古大能以自身道基铸就
- **天堑的真相**：天堑不是天然屏障，而是一场远古战争留下的伤疤——"封魔之战"
- **宗门暗流**：
  - 天剑宗的"剑冢"中封印着一柄禁忌之剑，据说能斩断因果
  - 万法阁的创始人是幽冥殿叛逃的弟子，两宗的恩怨已延续三千年
  - 灵兽山的妖兽并非完全被驯服，部分"灵兽"拥有远古记忆
  - 散修联盟的领袖是一位隐藏实力的渡劫期大能，目的不明
- **心魔的本质**：心魔不是幻象，而是修士自身业力的具象化——每一次杀戮、每一次背叛，都会喂养心魔

#### 第三层：深层（传说猎人专属）— 金丹期以上

为寻找隐藏房间、破解密文、拼合碎片化线索的玩家准备的内容。

- **苍玄界的起源**：苍玄界本身是一位陨落的仙人的尸骸化成——"苍玄仙帝"
- **封魔之战**：被封印的不是"魔"，而是仙帝的另一半意识——代表毁灭的意志
- **天劫的本质**：天劫不是天道对修士的考验，而是仙帝残存意识对"可能的继承者"的筛选
- **飞升的真相**：所谓飞升，其实是被仙帝残意识吞噬——真正的永生，需要找到另一条路
- **"大道"的真正含义**：每个修士追求的"大道"其实是一条个性化的人生哲学，不是力量，而是答案
- **隐藏线索**：
  - 灵兽山的某只神话宠物（青龙）体内封印着仙帝的一缕神识
  - 妖兽林深处的上古符文与万法阁的禁术同源
  - 青云镇的古井连接着苍玄界的"根部"——仙帝的心脏所在

### 2.3 世界圣经快速参考

#### 时间线

| 时代 | 事件 | 距今 |
|------|------|------|
| **仙帝纪** | 苍玄仙帝陨落，尸骸化为苍玄界 | ~100,000年 |
| **五脉纪** | 五位大能以自身道基铸就灵脉，开启修仙时代 | ~50,000年 |
| **封魔纪** | 封魔之战，天堑形成，幽冥殿被逐出中原 | ~3,000年 |
| **宗门纪** | 四大宗门格局形成，仙城建立 | ~1,000年 |
| **当前** | 玩家故事开始 | 现在 |

#### 派系

| 派系 | 理念 | 与玩家关系 | 关键NPC |
|------|------|-----------|---------|
| **天剑宗** | 以剑入道，追求极致力量 | 默认宗门（新手引导） | 苏玄清（师尊）、剑无痕（师兄） |
| **万法阁** | 博采众长，研究万法之源 | 可选加入（筑基后） | 莫千秋（阁主）、林婉儿（师姐） |
| **幽冥殿** | 以身为炉，炼化万物为己用 | 敌对势力（主线反派暗线） | 冥渊（殿主） |
| **灵兽山** | 人兽共生，追求自然和谐 | 宠物系统核心关联 | 白鹿真人（山主） |
| **散修联盟** | 自由至上，反抗宗门垄断 | 中立，后期盟友 | "老陈"（神秘领袖） |

#### 世界规则

- **灵气**：天地间的基本能量，修仙者通过功法吸收转化为修为
- **境界**：练气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 飞升（每一境界分多层）
- **心魔**：修士内心阴暗面的具象化，境界突破时必须面对
- **天劫**：突破大境界时天降的考验，实力越强劫雷越猛
- **灵石**：蕴含灵气的矿石，是修仙界的通用货币
- **功法**：修炼的方法，决定灵气转化为修为的效率
- **法宝**：注入灵气的器物，可增强战斗力
- **妖兽**：吸收灵气进化的野兽，体内可能含有珍贵材料

#### 禁止追溯修改

以下为第一层已确立的事实，后续内容不得矛盾：

1. 天剑宗是玩家默认起始宗门
2. 苏玄清是玩家的师尊，天剑宗外门长老
3. 青云镇是玩家出生的凡人小镇
4. 修仙境界体系：练气 → 筑基 → 金丹 → 元婴（已实现的四级）
5. 心魔是境界突破的考验机制
6. 灵石是通用货币
7. 宠物（灵兽）可以参与战斗

## 3. 核心角色设计

### 3.1 苏玄清 — 师尊

## 角色：苏玄清

### 身份
- **故事角色**：导师 / 引路人 / 隐藏深度
- **核心创伤**：三百年前的"封魔余波"中失去了挚友——也是他唯一输过的对手。他表面上是一个温和的退休长老，实际上是在天剑宗看守某个封印
- **欲望**：找到一个能超越自己、完成自己未竟之业的弟子
- **需求**：学会放手——他已经把"培养传人"当作逃避面对自己心魔的方式

### 声优支柱
- **词汇**：半文半白，偶尔夹杂修仙术语，但对新手会自动切换通俗说法。使用"为师""你小子""莫急"等称谓
- **句子节奏**：长句用于讲述道理（缓缓道来），短句用于关键时刻（"不对。""过来。""看好了。"）。偶尔的沉默比言语更有分量
- **他们避免的话题**：自己的过去、天剑宗的内部政治、为什么一个外门长老会住在偏远的青云镇
- **语言习惯**：
  - 喜欢用反问引导而非直接告知（"你觉得呢？"）
  - 夸奖很吝啬，但会在不经意间流露关心
  - 压力下语速变慢，而非变快
- **潜台词默认**：大部分时候说话留三分——"为师老了"实际意思是"我经历过你想象不到的事"

### 他们永远不会说的话
1. ❌ "修仙就是吸收灵气提升境界，很简单。" — 太像说明书，苏玄清不会这样解释
2. ❌ "哈哈哈，为师当年可是天下第一！" — 他从不自夸，且刻意淡化自己的实力
3. ❌ "孩子，你要记住，修仙最重要的是善良。" — 他不会灌输价值观，而是让玩家自己体会

### 参考台词（批准为声优示例）
- "练气三层……嗯。不算快，也不算慢。重要的是，你还在。" — 展示克制的关心
- "（沉默良久）……你问为师为什么住在这里？（笑了笑）这茶凉了，去续点热水来。" — 展示回避过去
- "心魔？不，那不是心魔。那是你自己在告诉你，你还没准备好。" — 展示洞察力

### 3.2 剑无痕 — 师兄

## 角色：剑无痕

### 身份
- **故事角色**：对手 / 盟友 / 竞争者
- **核心创伤**：出身天剑宗内门世家，从小被当作"天剑宗未来"来培养，所有情感需求都被"修炼进度"取代。他嫉妒玩家的自由和师尊的关注
- **欲望**：证明自己不需要出身和天赋也能成为最强
- **需求**：接受"够好了"——他永远无法成为第一，但第一并不重要

### 声优支柱
- **词汇**：简洁利落，偶带锋芒。从不使用敬语，对师尊例外。用语偏正式但不古板
- **句子节奏**：快而精确，像剑一样。不耐烦时句子更短。思考时偶尔会停顿（"……算了"）
- **他们避免的话题**：自己的家族、对师弟/师妹的真实看法、任何示弱的情感
- **语言习惯**：
  - 喜欢用事实和逻辑压制对方（"数据说明一切。"）
  - 失败后会变得异常沉默
  - 罕见的夸奖以行动代替言语（"给你留了一瓶丹药，别多想。"）
- **潜台词默认**：几乎总是说反话或轻描淡写——"我不在意"实际意思是"我在意得不得了"

### 他们永远不会说的话
1. ❌ "师弟/师妹，你真厉害，我比不上你。" — 他不会直接承认失败
2. ❌ "其实我一直很孤独……" — 他绝不会暴露脆弱，即使事实如此
3. ❌ "师父对你比对我好，我好嫉妒。" — 他会暗示，但永远不会说出口

### 参考台词
- "又来了？行吧。别拖后腿就行。" — 展示拒人千里但实际不排斥
- "（战斗后）你的剑法……比上次好一点。一点而已。" — 展示通过贬低来表达的认可
- "你不用每次都来找我切磋。我……也并不是每次都正好有空。" — 展示笨拙的社交

### 3.3 林婉儿 — 万法阁师姐

## 角色：林婉儿

### 身份
- **故事角色**：智者 / 友人 / 另一条路的代表
- **核心创伤**：幼年被万法阁收养，从未见过自己的父母。她在万法阁的万卷藏书中寻找"自己从何而来"的答案
- **欲望**：找到世间万法的终极规律——一个能解释一切的"公式"
- **需求**：接受"有些问题没有答案"——她寻找的不在书中，而在人与人的联系里

### 声优支柱
- **词汇**：温和而有书卷气，喜欢引用古籍但会立即解释（"《灵鉴》有云——嗯，简单说就是……"）。对不熟悉的人用敬语，熟悉后变得活泼
- **句子节奏**：中等长度，说话有条理，但兴奋时会变得语速加快、逻辑跳跃
- **他们避免的话题**：自己的身世、万法阁与幽冥殿的历史渊源
- **语言习惯**：
  - 喜欢类比（"修炼就像泡茶，火候不对，好茶也苦"）
  - 困惑时会自言自语（"不对不对，如果灵气是……等等，你还在？"）
  - 给人的建议总是温柔但坚定
- **潜台词默认**：她比表面上聪明得多——看似随口的闲聊，实际是在试探或传递信息

### 他们永远不会说的话
1. ❌ "哎呀，我什么都不懂啦~" — 她是真聪明，不会装傻
2. ❌ "别看书了，出去玩吧！" — 书是她安全的港湾，她不会劝别人远离
3. ❌ "万法阁和幽冥殿有什么关系？我完全不知道。" — 她知道，只是不能说

### 参考台词
- "你知道吗？万法阁有一本书，最后一页是空白的。不是没写完——是故意留白的。（停顿）我觉得那才是最重要的一页。" — 展示哲思
- "别担心灵石不够，办法总比困难多。至少……大概吧。大概率吧。六四开。" — 展示乐观+自嘲
- "（翻书声）……嗯？（抬头）抱歉，我在找一段记载。你刚才说什么？算了，你再说一遍，我听着呢。" — 展示沉浸与歉意

### 3.4 冥渊 — 幽冥殿殿主（暗线反派）

## 角色：冥渊

### 身份
- **故事角色**：暗线反派 / 镜像 / 另一种答案的代表
- **核心创伤**：曾经是天剑宗最有天赋的弟子，因为追求"禁忌之力"被逐出宗门。他相信修仙的终点不是飞升，而是成为新的"天道"
- **欲望**：打破现有的修仙秩序——他认为天劫、境界、心魔都是"囚笼"
- **需求**：意识到"打破规则"和"成为暴君"之间的区别

### 声优支柱
- **词汇**：平静到令人不安。用语古雅但含义晦涩。从不提高音量
- **句子节奏**：极慢，每个字都像是精心挑选的。停顿是武器——让听众自己填充恐惧
- **他们避免的话题**：自己的真实目的（他会用看似合理的理由包装一切）
- **语言习惯**：
  - 喜欢扭曲他人的话（"你说'正义'？有趣。谁定义的正义？"）
  - 永远不正面回答问题（"你觉得呢？"但与苏玄清的反问不同——苏玄清在引导，冥渊在瓦解）
  - 对"规则"一词有微妙的反应（会说"枷锁"代替"规则"）
- **潜台词默认**：他说的每句话都至少有两层意思——表面听起来有道理，深层则是诱骗

### 他们永远不会说的话
1. ❌ "哈哈哈，我是邪恶的！" — 他不认为自己是邪恶的，这才是可怕的
2. ❌ "我要毁灭世界！" — 他的目标比毁灭更复杂——他要"解放"世界
3. ❌ "你太弱了，不可能打败我。" — 他不会小看任何人，反而会过度关注有潜力的修士

### 参考台词
- "你不觉得奇怪吗？修了一辈子的仙，到头来……不过是在别人的棋盘上走了一步。" — 展示思想渗透
- "我不是你的敌人。（停顿）是你的另一个选项。" — 展示镜像定位
- "天剑宗教你要'正道'。万法阁教你要'智慧'。灵兽山教你要'和谐'。但没有人问过你——你想要什么。" — 展示对玩家能动性的尊重（也是操控）

### 3.5 白鹿真人 — 灵兽山山主

## 角色：白鹿真人

### 身份
- **故事角色**：宠物系统引导者 / 自然守护者 / 隐藏信息源
- **核心创伤**：他的本命灵兽在封魔之战中牺牲，他独自守护灵兽山数百年，将所有爱倾注在灵兽身上
- **欲望**：让人与灵兽真正理解彼此——而非利用
- **需求**：从"替代式关爱"中走出来，重新与人建立深层连接

### 声优支柱
- **词汇**：朴素自然，像老农多于像修士。偶尔会以动物的视角描述事物（"你看那只小狐狸，它不是因为忠诚才留下——它是因为这里安全。"）
- **句子节奏**：不急不缓，像溪水一样。讲故事时很吸引人，讲道理时很枯燥（他自己也知道）
- **他们避免的话题**：封魔之战的细节、为什么灵兽山不允许某些人进入
- **语言习惯**：
  - 对灵兽说话比对人对人还温柔
  - 会突然转移话题（"对了，你那只灵猫吃东西了吗？"）
  - 失去灵兽时会变得异常沉默和疏远
- **潜台词默认**：看似简单的老者，实际上知道的比苏玄清还多——但他选择不说

### 他们永远不会说的话
1. ❌ "灵兽就是工具，用好就行。" — 这是对他最大的侮辱
2. ❌ "你必须加入灵兽山才能养好灵兽。" — 他尊重自由选择
3. ❌ "当年那只白鹿死了，我很难过。" — 他从不直接表达悲伤

### 参考台词
- "（蹲在灵狐旁边）你看，它在磨爪子。不是攻击你——是在适应你的气味。它还不太信任你，但它在尝试。（抬头）这比你做的很多事情都勇敢。" — 展示洞察+温柔

- "封魔之战？那是大人物的事。我只是一只白鹿的伙伴。（长时间沉默）……只是一只。" — 展示沉痛

```
    + "即使如此，我也要走下去。路是自己选的，不是世界给的。" [坚定道心]

        → 后续：苏玄清赠送"天剑宗传承令"，正式收为亲传弟子

    + "……你说的是真的吗？有没有另一种可能？" [怀疑探求]
        → 心魔战斗难度降低，胜率80%（因为质疑本身就是一种清醒）
        → 后续：林婉儿赠送万法阁"空白书页"，暗示传说第三层

    + "（沉默）" [接受现实]
        → 心魔战斗难度提高，胜率60%（因为沉默代表动摇）
        → 后续：冥渊在战斗后第一次亲自出现——"你和我一样，看到了真相。"
        → 解锁"幽冥殿"暗线任务
```

**设计意图**：这是玩家在整个游戏中最重要的一个叙事选择——它影响第三幕后半和第四幕的走向。但注意，三条路线最终都会汇合到同一个结局（元婴期），只是体验路径不同。

### 4.5 第四幕：苍穹之问（元婴期 20层）

#### 幕主题：超越与传承

玩家已经站在苍玄界的顶端。最终的故事不是关于打败谁——而是关于"你成为了什么"。

#### 主要叙事节拍：

1. **天劫将至**：苍玄界出现异象，天劫比以往任何一次都要强大——因为仙帝的残意识正在觉醒
2. **所有势力的反应**：四大宗门、散修联盟各有对策，玩家成为关键力量
3. **最终选择**：不是战斗选择——而是"哲学选择"

#### 最终场景（元婴突破后触发）：

```
// 场景：苍玄界最高处 — 天堑之巅
// 所有主要角色齐聚

苏玄清: "天劫要来了。不是你的天劫——是整个苍玄界的天劫。"
冥渊: "仙帝要醒了。他沉睡了十万年，够了。"
剑无痕: "所以我们怎么办？打？"
林婉儿: "……不一定非要打。也许可以谈。"
白鹿真人: "（摸着一只白鹿）该来的总会来。"

→ [最终选择：你的道？]
    + "守护。苍玄界是我的家，里面的人——不管修士还是凡人——都值得活下去。" [守护之道]
        → 触发"守护结局"：玩家成为苍玄界的新守护者，如同师尊守护封印一样
        
    + "解放。仙帝不应该被困在这里——如果他能醒来，也许我们能找到让他安息的方法。" [解放之道]
        → 触发"解放结局"：玩家尝试与仙帝残意识沟通，寻找和平解决的方式
        
    + "超越。我不做守护者，也不做解放者——我要走自己的路。苍玄界之外，一定还有别的东西。" [超越之道]
        → 触发"超越结局"：玩家选择离开苍玄界，踏上未知的旅途

→ 所有结局后：
苏玄清: "（微笑）为师教了你这么多年……最后这一课，是你教为师的。"
苏玄清: "去吧。不管你选了什么路——"
苏玄清: "——别忘了回头看看。"
```

**设计意图**：
- 三个结局没有"对错"之分
- 每个结局都是开放式的——暗示故事还会继续
- 最后的传承感：师徒关系在最后一刻得到圆满

## 6. 环境叙事设计

### 6.1 青云镇 — 新手村

**这里发生了什么**：青云镇是一个灵气稀薄的小镇，坐落在天剑宗山脚。镇上的人大多不知道修仙界的存在，只知道"山上住着些厉害的人"。最近几年，镇子开始出现一些异象——井水有时会泛灵光，山上的兽鸣比以前更频繁了。

**玩家应该推断什么**：苍玄界的灵气在增强——这与仙帝残意识的觉醒有关。玩家在后期会发现这个"伏笔"。

**保持神秘的内容**：古井通向哪里？镇东头那间永远关着门的房子里住着谁？

**道具和放置**：
- **古井旁的裂缝**：镇口枯井旁有细微的灵纹裂缝，后期可以互动发现线索（第三层传说）
- **杂货铺的老陈**：他卖的药材品质远超普通货——暗示身份（第二层传说）
- **镇中心的石碑**：刻着模糊的铭文，只有练气5层以上才能勉强辨认（第一层传说）
- **镇外的小路**：通向天剑宗的山路上散落着前人留下的修炼笔记碎片

### 6.2 天剑宗 — 主宗门

**这里发生了什么**：天剑宗建立在一条中型灵脉之上，已有千年历史。宗门表面上是正道领袖，但"剑冢"中封印着禁忌之剑，苏玄清在山下的青云镇看守封魔残气。

**玩家应该推断什么**：天剑宗比外表看起来古老得多，宗门中有些区域连内门弟子也不可进入。

**保持神秘的内容**：剑冢深处封印着什么？藏经阁最上层为什么空着？

**道具和放置**：
- **练功场墙上的剑痕**：越靠近长老区剑痕越深——暗示高层战斗的强度
- **藏经阁的灰尘**：最下层的书架灰尘最厚——说明很少有人来底层修炼
- **后山的灵兽痕迹**：不时能看到不属于宗门灵兽的脚印——暗示有野生灵兽来访
- **剑冢入口的封印**：外门弟子看不到，内门弟子能看到但无法进入——制造好奇心

### 6.3 妖兽林 — 战斗区域

**这里发生了什么**：妖兽林是灵脉交汇处的一片古老森林，灵气浓郁导致野兽变异为妖兽。三千年前的封魔之战在这里留下了巨大的伤疤——森林中央有一个永远弥漫黑雾的深谷。

**玩家应该推断什么**：黑雾不是自然的——它是封魔封印泄漏的魔气。越靠近深谷，妖兽越凶猛、越不自然。

**保持神秘的内容**：深谷底部有什么？

**道具和放置**：
- **古战场的残骸**：散落的武器碎片和护甲残片，来自三千年前的战斗
- **变异妖兽**：靠近深谷的妖兽会出现不自然的特征（双瞳、黑色纹路）——暗示魔气侵蚀
- **被封印的石碑**：深谷边缘有一座断裂的石碑，上面的封印符文已经黯淡
- **灵兽的回避**：玩家携带的灵兽在接近深谷时会表现出不安

**灯光故事**：外围明亮温暖（阳光透过树叶），越深入越暗，深谷入口完全黑暗

**声音故事**：外围是鸟鸣和溪水，深处是低沉的咆哮和"像呼吸一样的"低频嗡鸣

**层级**：[x] 表面  [x] 参与  [x] 深层

### 6.4 万法阁 — 可选宗门

**这里发生了什么**：万法阁看起来像一个巨大的图书馆，实际上是一座活着的建筑——它会根据阅读者的修为展示不同的内容。创始人原本是幽冥殿弟子，后来叛逃建立了万法阁。

**玩家应该推断什么**：万法阁对"禁忌知识"的态度比天剑宗开放得多——甚至有些危险地开放。

**保持神秘的内容**：最后一页空白的书是谁留下的？为什么？

**道具和放置**：
- **自动排列的书架**：书架会在玩家走近时重新排列——暗示建筑有意识
- **被撕掉的页面**：某些古籍中关键页面被人为撕掉——有人在隐藏什么
- **林婉儿的书桌**：上面放着一本打开的族谱，但姓氏部分被墨水涂掉了——暗示她的身世

## 附录A：对话设计检查清单

每次编写新对话时，对照以下清单：

- [ ] **真人测试**：这行听起来像真人会说的话吗？不像作者写的？
- [ ] **声优一致性**：这个角色的词汇、节奏、习惯是否符合声优支柱？
- [ ] **无"如你所知"**：是否有角色在向另一个角色解释他们都知道的事情？
- [ ] **戏剧功能**：每个对话节点是否有清晰的戏剧功能？（揭示/关系/压力/后果）
- [ ] **选择有意义**：玩家选择是否在不同价值观之间做选择，而非不同语气？
- [ ] **2场景内后果**：分支选择是否在2个场景内产生可观察的后果？
- [ ] **自然汇合**：所有分支是否在合理的位置自然汇合？（除非有设计理由）
- [ ] **无信息倾倒**：传说投放是否分散在多个对话和环境中？
