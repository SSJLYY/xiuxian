## 1. 设计支柱

> 每一个设计决策都必须对照这五条支柱检验。不满足任意一条的功能，不进入实现队列。

### 支柱一：「每一分钟的挂机都有意义」
玩家离线时间必须产生可感知的进度。不论在线还是离线，玩家应该能清楚地看到"我不在线的这8小时，我做了什么"。
- **实现检验**：离线奖励界面必须展示详细收益分解，而不只是数字堆叠。

### 支柱二：「每次上线都有新鲜感」
不能让玩家每次上线的操作完全相同。每次会话必须有至少一个"今天不同于昨天"的元素。
- **实现检验**：每日任务、限时活动、宠物状态变化、拍卖行动态，任何一个必须有新内容。

### 支柱三：「选择有重量」
装备哪个技能、培养哪只宠物、先提升哪个属性——这些选择必须有真实的权衡，不存在"最优解"。
- **实现检验**：不能存在单一最优Build路径；技能树、宠物类型、装备套装必须各有适用场景。

### 支柱四：「成长有节奏感」
玩家应该感受到境界突破的庄重、普通升级的积累感。节奏 = 小奖励（每小时）+ 中奖励（每天）+ 大奖励（每周/突破）。
- **实现检验**：玩家在2小时会话内必须至少体验一次明显的"里程碑"（升级/技能解锁/宠物进化）。

### 支柱五：「社交有杠杆，单人也完整」
宗门、排行榜、拍卖行是加速器，而不是必需品。单人玩家可以体验完整内容，但社交行为可带来1.2-1.5倍的效率增益。
- **实现检验**：所有核心内容（境界突破、神话宠物、顶级装备）单人可获得，只是更慢。

## 2. 核心游戏循环

### 即时循环（0-30秒）

```
[玩家行动]  →  [即时反馈]  →  [微奖励]
 点击战斗       战斗动画       +EXP / +灵石
 点击修炼       修炼粒子效果   修炼速度倍率显示
 喂食宠物       宠物表情变化   +忠诚度数字飘字
 使用物品       音效+特效      属性变化提示
```

**关键体验目标**：每一次点击都要有即时的视听反馈，让玩家感知到"我的操作有效"。

**当前问题**：战斗日志目前是纯文字列表，建议加入伤害数字飘字和色彩区分（我方伤害=金色，受击=红色，暴击=橙色大字）。

### 会话循环（5-30分钟）

```
[进入游戏]
    ↓
[领取离线奖励] — 禀赋效应触发：展示"我离线期间获得了什么"
    ↓
[检查日常任务] — 形成当日目标感
    ↓
[主要活动选择]
    ├── 战斗刷图 → 经验/灵石/装备掉落
    ├── 修炼挂机 → 修炼点数/经验
    ├── 宠物管理 → 训练/喂食/升级
    └── 装备强化 → 消耗材料提升战力
    ↓
[阶段里程碑检查] — 是否即将升级？是否技能可解锁？是否可突破境界？
    ↓
[留存钩展示] — "再战一场就能升级" / "宠物饱食度明天会降低"
    ↓
[退出 → 离线修炼开启]
```

**张力机制**：
- 资源有限（灵石/材料），需要做取舍决策
- 宠物饱食度自然衰减，创造"明天要记得回来"的记挂感
- 当前等级进度条可见，形成"再一步就升级"的拉力

### 长期循环（天/周/月）

| 时间维度 | 里程碑 | 玩家体验 |
|---------|--------|---------|
| **每天** | 日常任务重置、每日签到 | "今天的任务完成了没有" |
| **每周** | 周任务重置、宗门周活动 | "本周贡献点能冲榜吗" |
| **每月** | 月任务、排行榜结算 | "这个月能不能进前10" |
| **非固定** | 境界突破（3-7天一次）| "突破了！感觉质变了" |
| **非固定** | 神话宠物捕获 | "终于捕到青龙！" |

**留存钩设计**：
- **连续签到**：第7天额外奖励稀有宠物捕获道具，断签从第1天重算
- **宠物羁绊**：给宠物命名后，触发禀赋效应，玩家不舍得不回来
- **宗门贡献**：每周排名，社会认可驱动

## 3. 境界与等级进度曲线

### 3.1 问题诊断（现有数值分析）

**当前数据（已有）：**
```
练气期 1层: 0-100 exp     (跨度 100)
练气期 2层: 100-250 exp   (跨度 150, +50%)
练气期 3层: 250-450 exp   (跨度 200, +33%)
...
练气期 10层: 2700-3250    (跨度 550)
筑基期 1层: 3250-4000     (跨度 750, 较上层+36%)
...
金丹期 1层: 8800-11000    (跨度 2200)
元婴期 1层: 20000-25000   (跨度 5000)
```

**发现的设计问题**：
1. **增长曲线过于线性**：练气期1-10层经验跨度只增长了5.5倍，但到金丹期突然飙升，玩家感觉"越练越慢"而没有"越练越厉害"的正反馈
2. **境界突破无仪式感**：筑基→金丹的经验跨度差距（550 vs 2200）会让玩家感觉"卡关"而非"挑战"
3. **战斗经验收益不透明**：lv1怪给50exp，但升级需要100exp——只需2场战斗就升级，太快，早期无挂机动机

### 3.2 建议进度曲线（重新设计）

**设计原则**：
- 每个境界内，升级速度应该感觉"稳步推进"
- 境界之间的"门槛感"通过特殊突破机制体现，而非单纯经验跳升
- 目标会话时间：练气期1-10需约3天（轻度玩家5-7天）

**修正后的经验曲线公式**：

```
境界内升级经验 = base_exp × (1 + level_in_realm × 0.3) × realm_multiplier

境界倍率：
  练气期 = 1.0
  筑基期 = 2.5
  金丹期 = 6.0
  元婴期 = 15.0
  化神期 = 40.0（未来扩展）
  渡劫期 = 100.0（未来扩展）
```

### 3.3 境界突破机制（新设计）

**问题**：现有设计只要经验到达就自动突破，缺乏仪式感和策略性。

**建议机制：境界突破考验**

```
当等级达到境界上限时（如练气期十层满级），不自动进入筑基期。
玩家需要：
  1. 准备"破境丹" × 1（任务/战斗/商城均可获得）
  2. 选择「冲击境界」
  3. 触发特殊战斗："境界心魔" — 难度对应当前战力，胜率约70%
  4. 成功：突破境界，属性大幅提升，获得专属称号
  5. 失败：保留等级，需再等1小时"冷却"，消耗更少资源重试
```

**玩家体验目标**：境界突破不是点击确认，而是值得庆祝的时刻。

## 4. 战斗系统机制规格

### 4.1 当前战斗公式分析

**已有代码中的伤害公式**（CombatService.java）：
```java
// 需补充查看 calculateDamage 方法具体实现
// 临时怪物生成公式：
health = 80 + level × 15 × typeMultiplier
attack = 8 + level × 2 × typeMultiplier  
defense = 3 + level × 1 × typeMultiplier
```

**发现问题**：
1. **防御力价值失衡**：玩家初始防御5，怪物lv1攻击10，每次受10点伤害（扣初始HP100）。10回合就死，但怪物HP只有100，玩家攻击10，也是10回合。几乎是硬拼，防御没有价值。
2. **暴击/闪避机制缺失**：战斗太线性，缺少随机张力
3. **宠物参与战斗缺失**：宠物只是养成模块，没有真正影响战斗

### 4.2 战斗公式重设计

#### 基础伤害公式（建议修改）
```
基础伤害 = max(1, 攻击力 × (1 - 防御率))
防御率 = 防御力 / (防御力 + 攻击方等级 × 10)
最终伤害 = 基础伤害 × 随机浮动(0.85, 1.15)
暴击 = 随机 < 暴击率(默认5%) → 最终伤害 × 1.8
```

**示例验证（lv1玩家 vs lv1野狼）**：
```
玩家攻击=10，野狼防御=5
野狼防御率 = 5 / (5 + 1×10) = 5/15 = 33%
玩家对野狼基础伤害 = 10 × (1-0.33) = 6.7 → 约7
野狼HP=100，需要约15回合打败

野狼攻击=10，玩家防御=5
玩家防御率 = 5 / (5 + 1×10) = 33%
野狼对玩家基础伤害 = 10 × 0.67 = 6.7 → 约7
玩家HP=100，也是约15回合

→ 速度相近时，双方几乎同时死亡。lv1玩家胜率约50%
→ 需要装备或技能来打破平衡
```

> [占位符] 上面的计算验证了公式方向，具体系数需要测试5场以上后调整

#### 速度系统（改进建议）

当前：速度决定先后手（>=则先手）。建议改为：
```
行动顺序：根据速度比值决定行动次数
if 玩家速度 > 怪物速度 × 1.5:
    玩家行动2次 → 怪物行动1次（每轮）
else if 怪物速度 > 玩家速度 × 1.5:
    怪物行动2次 → 玩家行动1次（每轮）
else:
    正常交替
```
这样**速度属性**有了真实价值，而不是"仅决定谁先打"。

### 4.3 宠物参战机制（新增规格）

**机制名称**：灵兽助战

**目的**：让宠物系统真正影响战斗，而不只是展示型收藏

**玩家幻想**：我和我的伙伴并肩作战

**输入**：战斗开始时，激活的出战宠物自动参与

**输出**：
```
宠物参战规则：
  每N回合（N = 3 + 宠物速度/10），宠物发动技能一次
  宠物技能伤害 = 宠物攻击 × 技能系数
  宠物忠诚度越高，技能发动概率越高：
    忠诚度 0-30:  60%概率发动
    忠诚度 31-60: 80%概率发动
    忠诚度 61-100: 100%概率发动（还有5%触发"共鸣"，伤害×2）
```

**宠物参战对战斗节奏的影响**：
- 有宠物：胜率比同等级提升约20-30%（精英怪）
- 无宠物：正常难度
- 这形成了"养宠物值得"的动机

**成功条件**："宠物技能发动"时，前端要有明显的宠物出现动画+技能特效

**失败状态**：若宠物饱食度<20，参战效果降低50%（给喂食行为创造紧迫感）

**边界情况**：
- 宠物和玩家同时死亡？→ 算玩家失败（玩家HP=0触发失败判定）
- 宠物能否被怪物攻击？→ 当前建议**不能**（宠物纯输出，无需担心宠物HP管理复杂度）

### 4.4 地图/副本规格（扩展方向）

| 地图 | 推荐等级 | 怪物类型 | 特殊机制 | 最终奖励 |
|------|---------|---------|---------|---------|
| 新手村 | 1-5 | 普通 | 必胜保障 | 基础装备 |

## 5. 修炼经济系统

### 5.1 经济流图

```
[收入来源]                        [消耗出口]
战斗掉落灵石    →                 学习技能
修炼获得灵石    →  [灵石池]  →   购买装备
任务奖励        →                 强化装备
离线收益        →                 宠物喂食道具
宗门贡献回报    →                 破境丹
拍卖行卖出      →                 拍卖行购买
```

**经济风险分析（当前）**：
- 玩家初始灵石1000，学一个技能（火球术）需1000，几乎全部消耗
- 修炼每小时产出灵石不明确（代码中有spirit_stones_gained但无明确公式）
- **通胀风险**：若战斗掉落灵石过多，中期玩家灵石泛滥，装备和技能定价失去意义

### 5.2 灵石收支平衡设计

**目标**：中度玩家（每天在线4小时）的灵石状态：
- 前期（1-5级）：轻微紧张，每次消费都需权衡
- 中期（6-15级）：稳定流通，有余量规划
- 后期（16-20级）：主要消耗在强化和稀有道具，普通消费不再有压力

**建议修炼收益公式**：
```
每小时修炼灵石 = base_spirit_stones × cultivation_speed × realm_bonus
  base_spirit_stones = 20 + level × 5  [占位符]
  realm_bonus: 练气期=1.0, 筑基期=1.5, 金丹期=2.5, 元婴期=4.0
  cultivation_speed: 玩家的修炼速度倍率（技能/装备加成）
```

**建议战斗灵石奖励**：
```
战斗灵石 = (10 + 怪物等级 × 2) × 怪物类型倍率
  普通怪: ×1.0
  精英怪: ×2.5
  BOSS:  ×6.0
```

**建议技能价格**：

| 技能类型 | 价格范围 | 解锁等级 | 玩家存灵石天数 |
|---------|---------|---------|--------------|
| 基础功法 | 0（免费） | 1 | - |
| 一级攻击技 | 500-800 | 3 | 约半天 |
| 二级攻击技 | 2000-3000 | 8 | 约1天 |
| 三级法术 | 8000-12000 | 13 | 约2天 |
| 稀有被动技能 | 30000-50000 | 18 | 约5天 |

> 原则：每个有意义的消费决策，应该让玩家"存2-5天就能买"，既不太容易，也不遥不可及

### 5.3 通货膨胀防护机制

1. **灵石上限**：每个账户灵石上限 = 50000 × realm_bonus [占位符]，超出部分自动转为"修炼点数"
2. **装备强化材料消耗**：高强化等级（+7以上）需要消耗大量灵石，作为后期主要汇
3. **宗门捐献汇**：可将灵石捐献给宗门换取贡献点（单向，灵石不回收）
4. **拍卖行手续费**：交易金额的5%销毁

### 5.4 修炼点数独立经济

**修炼点数**独立于灵石存在，专用于：
- 技能熟练度加速
- 特殊丹药合成
- 被动技能解锁

与灵石汇率：**不可直接兑换**（防止资源套利）

## 6. 技能系统设计

### 6.1 技能类型分类与战略定位

| 技能类型 | 玩家幻想 | 适用场景 | 权衡 |
|---------|---------|---------|------|
| **修炼类** | "我的修炼效率是别人的两倍" | 挂机收益最大化 | 牺牲战斗力 |
| **攻击类** | "我一击制敌" | 战斗/BOSS | 消耗法力，无法自给 |
| **防御类** | "我不死" | 打BOSS/高难度地图 | 攻击输出低 |
| **被动类** | "我的基础属性压倒一切" | 全场景 | 价格昂贵，升级慢 |

**设计原则**：4种类型应形成真实的Build选择，而非存在明显最优解。

### 6.2 技能成长规格

**技能升级路径**（修正当前经验计算问题）：

```
技能升级所需经验 = base_exp × (current_level ^ 1.6)
  base_exp: 攻击技=100, 修炼技=80, 防御技=120, 被动技=200 [占位符]

技能效果成长（建议）：
  每级伤害倍率提升 = 基础伤害 × (1 + 0.15 × skill_level)
  每级冷却减少 = max(1s, 基础冷却 - 0.3s × skill_level) [占位符]
  每级法力消耗 = 基础消耗 × (1 + 0.05 × skill_level) — 消耗小幅增加
```

## 7. 宠物系统深度设计

### 7.1 当前系统问题

1. **饱食度衰减速度不明确**：玩家不知道"几小时后需要回来喂食"
2. **忠诚度对战斗无影响**（当前只有"影响战斗表现"这个模糊描述）
3. **宠物进化路线缺失**：小灵猫永远是小灵猫，没有成长叙事
4. **宠物差异化不足**：各宠物除稀有度不同，没有策略性差异

### 7.2 宠物属性重设计

#### 饱食度衰减速率（建议）
```
每小时自然衰减 = 2点
训练消耗 = 10点
战斗消耗 = 3点/次（宠物参战）

饱食度效果：
  100: 训练效果×1.3（"精力充沛"）
  80-99: 正常×1.0
  50-79: 训练效果×0.8
  20-49: 无法训练
  1-19: 战斗技能发动概率降低50%
  0: 无法参战，持续掉忠诚度(-1/h)
```

**目标**：每天需要回来喂食1-2次（约12小时清空），形成每日回归动机。

#### 忠诚度影响战斗（具体化）
```
忠诚度 → 战斗增益
  0-20:  宠物技能冷却时间×1.5（疲惫状态）
  21-50: 正常状态
  51-80: 技能伤害×1.1
  81-100: 技能伤害×1.25，偶发"共鸣"（×2伤害，概率5%）
```

### 7.3 宠物进化系统（新功能规格）

**机制名称**：灵兽蜕变

**目的**：让宠物有成长叙事，形成长期培养目标

**触发条件**：
```
进化条件（需同时满足）：
  1. 宠物等级达到进化门槛（普通→稀有：20级）
  2. 忠诚度 >= 80
  3. 消耗：进化丹 × 1（稀有材料）
  4. 可选：消耗灵石加速（跳过等待时间）
```

**进化路线表**：

| 原形态 | 进化条件 | 进化形态 | 属性变化 | 新技能 |
|-------|---------|---------|---------|--------|
| 小灵猫 | lv20+忠诚80+ | 灵虎 | 全属性+50%，攻击专精 | 虎啸（群体减速） |
| 灵狐 | lv20+忠诚80+ | 九尾灵狐 | 速度+80%, 法力+40% | 魅惑（BOSS眩晕） |
| 冰霜狼 | lv25+忠诚85+ | 霜狼魔君 | 防御+80%, HP+60% | 冰盾（伤害吸收） |

> **设计注意**：进化道具"进化丹"应稀缺但可获得，建议每周任务/宗门活动各给1个

### 7.4 宠物图鉴系统（建议）

**目的**：提供收藏动机，即使不用该宠物也有捕获价值

```
图鉴效果：
  收集1只宠物：记录入图鉴
  收集5只不同宠物：全局修炼速度+2%
  收集10只：全局攻击+5
  收集所有普通宠物（4只）：解锁"萌宠大师"称号
  收集4只神话宠物：解锁"四神守护"套装效果（全属性+15%）
```

## 8. 留存与新手引导

### 8.1 新手引导检查清单

- [x] **核心动词在30秒内引入**：登录后直接显示"开始修炼"按钮
- [ ] **第一次成功有保障**：第一场战斗必须是必胜（lv1野狼HP减半，或给1级保护盾）[需实现]
- [ ] **每个新机制在安全环境中引入**：技能系统有"免费试用"入口 [需实现]
- [ ] **玩家通过探索发现至少一个机制**：宠物初次出现应该是"偶然发现"而非提示引导 [待设计]
- [ ] **第一次会话以钩子结束**：首次登出前弹出"你的宠物需要明天喂食" [需实现]

### 8.2 关键挫折预防

**挫折点1：首次战斗失败**
- 当前：玩家lv1 vs lv1怪物，胜率约50%，首次可能失败
- 建议：首场战斗强制给lv1新手村怪物（属性×0.5），必胜
- **理由**：首场失败会导致25-30%玩家流失（来自行业数据）

**挫折点2：灵石耗尽**
- 当前：初始1000灵石，买一个技能就花完了
- 建议：初始给2000灵石，且第一个技能（基础功法）改为免费
- **理由**：让玩家在花光之前感受到"有能力选择"

**挫折点3：不知道该做什么**
- 当前：没有明确的引导序列
- 建议：新手任务链（串行任务，不能跳过）：
  ```
  Task 1: 开始第一次修炼（奖励：破境丹×1，说明用途）
  Task 2: 完成第一场战斗（奖励：基础装备）
  Task 3: 给你的宠物喂食（奖励：宠物技能书）
  Task 4: 学习第一个技能（奖励：高级修炼丹×3）
  Task 5: 达到练气期三层（奖励：稀有宠物捕获令×1）
  → 完成后解锁日常任务系统
  ```

## 10. 已知设计风险

### 高风险

1. **无目标感**：现有系统缺乏明确的中期目标。建议增加"个人成就线"系统，类似"主线任务"，告诉玩家"下一个大目标是什么"。

2. **战斗无深度**：纯数值比拼，没有策略。宠物参战机制和技能连招系统应优先实现，在数值调整前先解决"不好玩"的问题。

3. **离线收益单调**：永远是EXP+灵石，缺乏惊喜。建议离线时有1-5%概率触发"奇遇"——偶遇随机事件（免费宠物碎片、稀有材料等），让每次登录都有"看看今天遭遇了什么"的期待。

### 中风险

4. **拍卖行马太效应**：先发玩家垄断优质装备。建议设置拍卖行上架数量限制（每人每天最多3件）和价格上限（不超过同类装备商店价的3倍）。

5. **VIP设计张力**：VIP特权若过强，会损害公平体验，破坏支柱五。建议VIP特权仅提供**速度加成**（1.2×离线收益上限、1.1×经验），不提供专属内容。

6. **宗门不活跃**：若宗门没有真正需要协作的内容，只是共享加成，玩家不会深度参与。需设计至少一个"单人无法完成"的周内容（宗门BOSS）。
