# Skills Index

## 可用技能

### 1) 通用开发方向
- 路径：`skills/project-development-direction/SKILL.md`
- 用途：制定阶段目标、范围收敛、里程碑与迭代任务
- 触发词：开发规划、路线图、优先级、下一步做什么

### 2) 修仙项目开发方向
- 路径：`skills/xiuxian-development-direction/SKILL.md`
- 用途：围绕成长/战斗/资源/养成四主线做版本规划
- 触发词：修仙玩法规划、MVP、版本迭代、系统先后顺序

### 3) 修仙项目上下文
- 路径：`skills/xiuxian-project-context/SKILL.md`
- 用途：快速建立项目整体认知，定位模块落点、启动入口、配置入口与排障入口
- 触发词：通读项目、理解仓库、接手开发、定位功能、找实现入口、启动排查

## 使用建议

- 先用通用技能收敛目标，再用修仙技能做模块级拆解。
- 每次输出都要包含“本轮不做”与“测试补齐任务”。
- 涉及玩法改动时，必须补充“落地映射”（后端/前端/测试/文档）。
